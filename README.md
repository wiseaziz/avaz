# AVAZ

تطبيق ويب لتصفح وحجز سكن العمالة: أسرّة وغرف وشقق، بخمس لغات (العربية، English، اردو، Filipino، हिन्दी)، مع تحليل ذكي وتقييم متبادل صارم بين الساكن والمؤجر.

النسخة الحالية **تجريبية**: الصفحة مستضافة على GitHub Pages، والبيانات (الحسابات، الإعلانات، الحجوزات، التقييمات، الصور والفيديو) محفوظة أونلاين في Supabase.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | التطبيق كامل |
| `config.js` | رابط مشروع Supabase والمفتاح العام (publishable) |
| `supabase/schema.sql` | الجداول وقواعد الحماية، يُلصق مرة وحدة في SQL Editor |
| `manifest.webmanifest` والأيقونات | عشان ينضاف التطبيق للشاشة الرئيسية في الجوال |

## التشغيل لأول مرة

1. في Supabase افتح **SQL Editor** ثم **New query**، والصق محتوى `supabase/schema.sql` كامل واضغط **Run**. تشغيله مرة ثانية ما يضر.
2. في **Authentication ← Sign In / Providers ← Email** طفّ خيار **Confirm email** عشان الأصدقاء يدخلون بدون رسالة تأكيد.
3. افتح رابط الصفحة، وسجّل أول حساب **كمؤجر** وأضف وحدة أو وحدتين قبل لا ترسل الرابط للأصدقاء.

## مهم عن المفاتيح

- `config.js` فيه المفتاح العام فقط، وهذا آمن لأن قواعد الحماية في قاعدة البيانات هي اللي تحدد مين يقرأ ويكتب.
- **لا تحط المفتاح السري (`sb_secret_...`) في أي ملف هنا أبداً.**

## قواعد الحماية والتقييم (مطبّقة في قاعدة البيانات نفسها)

- كل مستخدم يعدّل بياناته هو فقط، والمؤجر يعدّل إعلاناته فقط.
- رقم الجوال ما يظهر للطرف الثاني إلا بعد قبول الحجز.
- الحجز يمشي بالترتيب: طلب ← قبول أو اعتذار من المؤجر ← إقامة ← إنهاء الإقامة.
- التقييم بعد إقامة منتهية فقط، وخلال 14 يوماً، ومرة وحدة لكل طرف، وما يتعدّل.
- خمسة معايير إلزامية، والتقييم العام يُحسب في قاعدة البيانات، وأي درجة نجمتين أو أقل تحتاج سبب مكتوب (30 حرف على الأقل).
- التقييم مخفي عن الطرف الثاني حتى يقيّم هو أو تمر 14 يوماً.
- حذف إعلان عليه حجوزات سابقة يخفيه بدل ما يمسحه، عشان تقييماته تبقى.

## التحديث الثاني

- **حسابات الشركات والمؤسسات:** تسجيل برقم السجل التجاري وعدد العمالة والميزانية لكل عامل، وحجز بالجملة أو عمارة كاملة لمدة تصل إلى 60 شهر، ونسبة توافق حسب السعة وتكلفة العامل.
- **عمارة كاملة:** نوع سكن جديد يضيفه المؤجر بإيجار شهري للعمارة وسعتها من العمال وعدد الشقق.
- **تأكيد بنعم أو لا** قبل إرسال طلب الحجز وقبل إنهاء الإقامة.
- **الميزات الذكية** (ترجمة الوصف والتقييمات، وكتابة وصف السكن) تشتغل من دالة `supabase/functions/ai` باستخدام Claude، بحد 40 طلب يومياً لكل مستخدم. تحتاج سر اسمه `ANTHROPIC_API_KEY` في **Edge Functions ← Secrets**، وتظهر أزرارها تلقائياً بعد إضافته.
- تعديلات قاعدة البيانات في `supabase/migrations/`، وهي مضافة أيضاً في آخر `schema.sql` للتركيب من الصفر.
